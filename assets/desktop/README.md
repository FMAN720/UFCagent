# UFC desktop shortcut icons

Original UFC wordmark: https://commons.wikimedia.org/wiki/File:UFC_Logo.svg

Vector file: https://upload.wikimedia.org/wikipedia/commons/9/92/UFC_Logo.svg

The source lists UFC as author and UFC.com as its origin. Original path geometry and proportions are preserved. The start icon uses white; the stop icon keeps the source red (#d20a0a), both on transparent backgrounds.

Windows ICO files contain 16, 24, 32, 48, 64, 128 and 256 pixel variants. Regenerate with `node scripts/build-desktop-icons.mjs`, then run `scripts/create-desktop-shortcuts.ps1` to apply. The artwork is used for this local application's shortcuts; it does not indicate UFC endorsement.
